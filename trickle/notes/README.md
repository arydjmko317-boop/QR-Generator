# QR Pro - Modern QR Generator

A powerful web application built with React and TailwindCSS for generating professional QR codes.

## Features
- **Dynamic Content Support**: URLs, Text, Email, WiFi, and VCard.
- **Customization**: Change foreground and background colors.
- **Advanced Controls**: Adjust margins, resolution, and error correction level.
- **Instant Preview**: Real-time generation as you type with precise layout alignment.
- **High-Quality Export**: Download as PNG or JPG.

## Tech Stack
- React 18
- TailwindCSS
- QRCode.js (Library)
- Lucide Static Icons
